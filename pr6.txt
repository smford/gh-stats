feat: Shift-Left Local Pre-Push Git Hook (gh-stats hook install) and examples

## Summary
This PR introduces **Shift-Left Local Git Hooks** to `gh-stats`, empowering developers and SREs to evaluate PR and branch risk locally on their workstations *before* pushing to remote CI/CD or opening pull requests.

### Key Capabilities
1. **One-Command Installation (`gh-stats hook install`):**
   - Installs a lightweight, portable git hook into `.git/hooks/pre-push` with executable `0755` permissions.
   - Configurable risk threshold (`--fail-on=HIGH`, `--fail-on=CRITICAL`) or inherits from `.gh-stats.yml`.
   - Supports pre-commit hooks (`--type=pre-commit`) for staged file evaluation.
   - Idempotent and safe: preserves existing non-gh-stats hooks unless `--force` is specified.
2. **Shift-Left Risk Evaluation (`gh-stats hook run`):**
   - Auto-detects the base branch (`origin/main`, `main`, etc.) and compares against `HEAD`.
   - Computes risk score, blast radius on sensitive files, and missing test deltas.
   - If risk meets or exceeds threshold, blocks the push with clear remediation tips and bypass instructions (`git push --no-verify` or `SKIP_GH_STATS=1`).
3. **Clean Hook Removal (`gh-stats hook uninstall`):**
   - Safely removes the installed hook after validating gh-stats marker ownership.
4. **Standalone Examples (`examples/hooks/`):**
   - Reference `examples/hooks/pre-push` script.
   - Reference `examples/hooks/pre-commit` script.
5. **CI/CD ShellCheck Quality Gate:**
   - Updated `.github/workflows/ci.yml` ShellCheck lint step to validate `examples/hooks/*` in addition to `scripts/*.sh`.
6. **Documentation:**
   - Added comprehensive usage guide, CLI examples, and architectural guidance to `README.md`.

## Changes
