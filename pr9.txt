feat: native OpenTelemetry (OTel) and Prometheus metric export capabilities

## Summary
This PR adds native OpenTelemetry (OTel) and Prometheus metric export capabilities to `gh-stats`, enabling engineering organizations to export PR, Release, Repository, and Environment Drift reliability metrics directly into modern observability platforms (Grafana, Mimir, Datadog, Prometheus Pushgateway, and OTel Collectors).

All metric exposition logic is built using the Go standard library with zero external dependencies, maintaining sub-second execution speeds and lean binary distribution.

### Key Capabilities
1. Prometheus Text Exposition Format (`--export-prom=metrics.prom`):
- Formats metrics in standard Prometheus text representation with `# HELP` and `# TYPE` declarations.
- Emits gauges and counters for PR lead time (`gh_stats_pr_lead_time_seconds`), SRE risk score (`gh_stats_pr_risk_score`), lines added/deleted/net (`gh_stats_pr_lines_*`), CI pipeline latency (`gh_stats_ci_latency_seconds`), flaky check runs count (`gh_stats_ci_flaky_checks_total`), release breaking changes count (`gh_stats_release_breaking_changes_total`), release deployment risk score (`gh_stats_release_risk_score`), environment drift commit divergence (`gh_stats_drift_commits_ahead`, `gh_stats_drift_commits_behind`), and drift risk score (`gh_stats_drift_risk_score`).
- Labels include repository slug, target scope, ref, and commit metadata.
- Supports file output for direct scraping, Prometheus Pushgateway ingestion, or textfile collector aggregation.
2. OpenTelemetry OTLP HTTP Export (`--export-otel-endpoint=http://otel-collector:4318/v1/metrics`):
- Dispatches standard OTLP JSON metrics over HTTP POST (`application/json`) to any OpenTelemetry collector, Grafana Cloud OTLP gateway, or Datadog OTLP ingest endpoint.
- Maps gauges and cumulative sum metrics with Unix nanosecond timestamps into resource and scope metrics.
- Supports custom headers via `--export-otel-headers` or `otel_headers` configuration (e.g. `Authorization`, `X-Scope-OrgID`, `dd-api-key`).
3. GitHub Action & Configuration Integration:
- Action inputs: `export-prom`, `export-otel-endpoint`, and `export-otel-headers`.
- Action outputs: `metrics-prom` (file path) and `otel-status` (`success` or `failure`).
- Config file (`.gh-stats.yml`): `export.prom_path`, `export.export_prom`, `export.otel_endpoint`, `export.export_otel_endpoint`, and `export.otel_headers`.
4. Observability Documentation & Guide:
- Expanded `README.md` with Grafana / Prometheus / Pushgateway, OpenTelemetry Collector, and Datadog ingestion examples.
- Added metric reference table and updated CLI flags list.
5. Example Workflow:
- Added `.github/workflows/test-metric-export.yml` supporting manual dispatch and artifact archiving.

## Changes
- `pkg/config/config.go`: Added `PromPath`, `ExportProm`, `OTelEndpoint`, `ExportOTelEndpoint`, and `OTelHeaders` to `ExportConfig` with helper methods `GetPromPath()` and `GetOTelEndpoint()`.
- `pkg/config/config_test.go`: Added tests validating YAML parsing and aliases for Prometheus and OTel export settings.
- `pkg/exporter/prometheus.go`: Implemented `GeneratePrometheusMetrics()` and `ExportPrometheus()`.
- `pkg/exporter/prometheus_test.go`: Added unit tests verifying Prometheus metric syntax, comments, types, and label formatting for PR, Release, and Drift payloads.
- `pkg/exporter/otlp.go`: Implemented standard OTLP HTTP JSON payload serialization (`BuildOTLPMetricsPayload`), header parsing (`ParseOTLPHeaders`), and HTTP dispatch (`ExportOTLP`).
- `pkg/exporter/otlp_test.go`: Added tests verifying OTLP JSON serialization, header parsing, HTTP endpoint posting, and error propagation.
- `cmd/gh-stats/main.go`: Added CLI flags `--export-prom`, `--export-otel-endpoint`, `--export-otel-headers`, config resolution, export execution, and GitHub Action step outputs.
- `action.yml`: Exposed `export-prom`, `export-otel-endpoint`, and `export-otel-headers` inputs, and `metrics-prom` and `otel-status` outputs.
- `README.md`: Added documentation for Prometheus and OpenTelemetry exporters, ingestion examples for Prometheus/Pushgateway, Grafana Cloud, and Datadog, updated configuration examples, and CLI flags list.
- `.github/workflows/test-metric-export.yml`: Added manual demonstration workflow for metric export.
