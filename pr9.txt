feat: PR risk budget & SRE SLO burn rate tracking

## Summary
Introduces automated Pull Request Risk Budget and SRE Service Level Objective (SLO) burn rate tracking to `gh-stats`. Engineering squads can now treat change risk like an error budget: monitoring cumulative risk points merged over a rolling window (e.g. 30 days), calculating real-time SLO burn rates, and enforcing automated quality gates before runaway risk leads to production outages.

## Key Changes
- **Configuration (`pkg/config` & `.gh-stats.yml`):**
Added `risk_budget` block with options:
`enabled`: toggle rolling risk budget analysis
`monthly_risk_points`: squad risk point allocation (e.g. 500 pts)
`window_days`: rolling historical evaluation window (default: 30 days)
`max_critical_prs`: maximum allowable CRITICAL PRs (score >= 75) in the window
`burn_rate_alert_ratio`: alert multiplier (default: 1.0x)

- **Git History Telemetry (`pkg/gitutil`):**
Added `GetMergedPRHistory(baseRef, since)` and `ParseMergedPRHistory` to mine merged PR commits, timestamps, and line diff stats along `--first-parent -m` without external database dependencies.

- **Risk Budget & SLO Burn Engine (`pkg/analyzer`):**
Added `CalculateHistoricalCommitRisk` to score historical merged PRs based on size, test-to-code velocity, and sensitive file blast radius.
Added `EvaluateRiskBudget` to project total cumulative points (`Historical + Current PR`), compute utilization percentage, and derive observed SLO burn rate:
`Burn Rate = (Observed Daily Risk Points) / (Sustainable Daily Budget Rate)`
Computes squad status: `HEALTHY`, `ELEVATED` (>=80% budget or burn >= alert ratio), and `EXCEEDED` (>100% budget or exceeded critical PR limit).
Added SARIF rule `RulePRRiskBudgetExceeded` (`GHSTATS010-RISK-BUDGET-EXCEEDED`) with error severity when budget is depleted.

- **Markdown Step Summary (`pkg/reporter`):**
Added `## 📉 PR Risk Budget & SRE SLO Burn Rate` section featuring status badges, utilization %, burn rate multiplier, critical PR counter, and a recent merged PR breakdown table.

- **CLI & Action Integration (`cmd/gh-stats`, `action.yml`):**
Added CLI flags: `--risk-budget-points`, `--risk-budget-window`, `--risk-budget-max-critical`, and `--fail-on-risk-budget`.
Exposed GitHub Action inputs and step outputs: `risk-budget-utilization`, `risk-budget-burn-rate`, `risk-budget-status`, `risk-budget-points-used`.
Enforced quality gating in `cmd/gh-stats` to fail the run when `--fail-on-risk-budget` is set and status is `EXCEEDED`.

- **Metrics & Observability (`pkg/exporter`):**
Added Prometheus gauges (`gh_stats_risk_budget_utilization_percent`, `gh_stats_risk_budget_burn_rate`, `gh_stats_risk_budget_points_total`) and OTLP metrics telemetry.

- **Documentation & Web Playground (`README.md`, `docs/index.html`):**
Documented risk budgeting architecture, configuration examples, and CLI flags in `README.md`.
Added feature card and updated SARIF rules table in `docs/index.html`.
