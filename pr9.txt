feat: interactive terminal UI dashboard (gh-stats tui)

## Summary
Introduces a zero-dependency interactive Terminal UI (TUI) dashboard to `gh-stats` (`gh-stats tui` or `--tui`). The dashboard elevates local developer experience during branch development and code review by presenting visual SRE risk ratings, scrollable blast radius file inspections, interactive commit changelogs, and domain expert reviewer recommendations directly inside the terminal.

## Key Changes
- **CLI Integration (`cmd/gh-stats`):**
Added `tui` subcommand (`gh-stats tui`) and `--tui` flag.
Defaults target to `pr` mode for local branch reviews against base.
Suppresses console logs when launching interactively to keep terminal displays clean.

- **TUI Dashboard Engine (`pkg/tui`):**
Built a lightweight, zero-dependency TUI using ANSI escape sequences and terminal raw mode.
Implemented 4 interactive dashboard views:
1. SRE Risk Overview: Visual risk score meter gauge, metrics summary, and complete risk factor breakdown.
2. Files & Blast Radius: Scrollable list of modified files with additions/deletions, sensitive blast radius badges (CI/CD, Migrations, Security), and selected file details pane.
3. Commits & Changelog: Categorized commit history with conventional commit badges ([FEAT], [FIX], [BREAKING]), author metadata, and selected commit preview pane.
4. Domain Reviewers: Suggested component code owners and historical commit velocity.

- **Graceful Fallback:**
Detects non-interactive environments and CI runners (`[ -t 1 ]`, `CI`, `TERM=dumb`).
Gracefully renders structured plain text output when running non-interactively without terminal corruption.

- **Unit Testing & View Models (`pkg/tui/view_test.go`):**
Comprehensive tests covering `DashboardModel` navigation, cursor bounds, page scrolling, and tab switching.
Verified rendering outputs across all tabs, help overlays, and non-interactive plain text fallbacks.

- **Documentation & Web Playground (`README.md`, `docs/index.html`):**
Updated `README.md` with TUI navigation keys table, CLI usage examples, and command flags.
Updated `docs/index.html` with TUI feature card.
