feat: Environment Drift & Promotion Audit mode (--target=drift)

## Summary
This PR introduces the Environment Drift & Promotion Audit mode (`--target=drift`), providing teams with automated SRE intelligence and risk evaluation before promoting changes between deployment environments (such as staging to production).

In continuous delivery workflows, long-lived branch divergence between environments frequently leads to high-risk batch releases, unpromoted database migrations, and deployment failures. With `--target=drift`, `gh-stats` audits ahead/behind commit divergence, unpromoted sensitive infrastructure and schema changes, calculates a promotion deployment risk score (0-100), emits SARIF security findings, exports DORA metrics, and renders rich Markdown step summaries.

### Key Capabilities
1. Environment Drift Audit CLI (`cmd/gh-stats`):
- Added `--target=drift` mode comparing target base environment (e.g. `--base=origin/production`) with candidate source environment (e.g. `--head=origin/staging`).
- Automated branch resolution with sensible defaults and remote prefix handling (`origin/production`, `origin/staging`, `HEAD`).
- Quality gate enforcement with `--fail-on` (e.g. `--fail-on=HIGH` blocks promotion when drift risk exceeds threshold).
2. Drift Metrics & Risk Engine (`pkg/analyzer`):
- Commits ahead: unpromoted commits queued in candidate environment waiting for release.
- Commits behind: upstream divergence / hotfixes on base environment missing from candidate.
- Unpromoted breaking changes: conventional commits breaking syntax (`feat!:`, `BREAKING CHANGE:`) and schema migrations (`migrations/`, `*.sql`).
- High blast radius tracking: unpromoted changes to infrastructure, containers, CI/CD pipelines, and auth modules.
- Promotion Deployment Risk Score (0-100) and qualitative risk tiers (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`).
3. Markdown Step Summary Table (`pkg/reporter`):
- Renders dedicated `🌐 Environment Drift & Promotion Assessment` summary table in `$GITHUB_STEP_SUMMARY`.
- Highlights base and candidate environments, ahead/behind counts with status indicators, net lines moved, breaking changes, and candidate commit queue.
- Shows in-sync confirmation banner when environments have zero divergence.
4. DORA & Observability Telemetry Export (`pkg/exporter`):
- Added `DriftMetrics` struct and `NewDriftPayload` constructor.
- Exports structured drift telemetry into DORA payloads for JSON logging or webhook dispatch.
5. SARIF Security & Reliability Rules (`pkg/analyzer`):
- `GHSTATS301-DRIFT-SUMMARY`: Environment drift and promotion audit summary (`note`).
- `GHSTATS302-DRIFT-EXCESSIVE`: Excessive commit divergence detected between deployment environments (`warning`).
- `GHSTATS303-DRIFT-UNPROMOTED-BREAKING`: Unpromoted breaking changes or database schema migrations waiting between environments (`warning`).
- `GHSTATS304-DRIFT-UNPROMOTED-SENSITIVE`: Unpromoted critical infrastructure, CI/CD pipeline, or security configuration changes (`warning`).
6. GitHub Action Integration (`action.yml`):
- Added `drift` to target options.
- Exposes step outputs: `drift-base-ref`, `drift-head-ref`, `drift-commits-ahead`, `drift-commits-behind`, `drift-breaking-count`, `drift-sensitive-count`, `drift-risk-level`, and `drift-risk-score`.
7. Testing & Verification:
- Added `GetAheadBehind` runner method and synthetic test cases in `pkg/gitutil`.
- Added synthetic branch drift test cases in `pkg/analyzer/drift_test.go` covering clean sync, breaking changes, migrations, and excessive divergence.
- Added reporter tests in `pkg/reporter/markdown_test.go`.
- Added exporter tests in `pkg/exporter/exporter_test.go`.
