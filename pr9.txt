feat: publish and update GitHub Release notes with SRE summary (--publish-release-notes)

## Summary
This PR adds the ability to automatically publish or update GitHub Release notes using the generated SRE release summary (`--publish-release-notes`), providing rich, production-grade release documentation directly in GitHub Releases.

When deploying a release, manually drafting release notes or relying on basic git commit logs often leaves users and SREs blind to breaking changes, database migrations, and pipeline blast radius. This feature integrates `gh-stats` directly with the GitHub Releases API to publish structured, audit-ready release documentation.

### Key Capabilities
1. GitHub Releases API Client (`pkg/github`):
- `GetReleaseByTag`: Retrieves an existing release by tag name (`GET /repos/{owner}/{repo}/releases/tags/{tag}`).
- `GetReleaseByID`: Retrieves a release by its numeric ID (`GET /repos/{owner}/{repo}/releases/{id}`).
- `CreateRelease`: Creates a new release (`POST /repos/{owner}/{repo}/releases`).
- `UpdateRelease`: Updates release body or details (`PATCH /repos/{owner}/{repo}/releases/{id}`).
- `PublishOrUpdateReleaseNotes`: Intelligent high-level helper that inspects if a release already exists for the tag. If present, it non-destructively preserves existing binary download links or custom headers and updates the SRE release notes section (`<!-- gh-stats-release-notes -->`). If no release exists, it creates one.
2. CLI Flags (`cmd/gh-stats`):
- `--publish-release-notes`: Enables publishing or updating GitHub release notes with the SRE release summary.
- `--release-tag`: Target release tag for publishing release notes. If omitted, automatically detects the tag from GitHub Actions environment (`GITHUB_REF_NAME`, `GITHUB_REF`), release delta `HeadRef`, `SuggestedVersion`, or repository tags.
- Automatically resolves target mode to `release` when `--publish-release-notes` is provided without explicit target.
3. GitHub Action Integration (`action.yml`):
- Added input `publish-release-notes: true/false`.
- Added input `release-tag`.
- Exposes step outputs `release-id` and `release-url`.
4. Comprehensive Release Documentation:
- Includes overall SRE deployment risk score and qualitative risk rating.
- Includes Release Delta Overview table (additions, deletions, net delta, file breakdown, recommended bump).
- Highlights Breaking Changes and database schema migrations (`*.sql`, `migrations/`).
- Generates categorized Conventional Commits changelog (Features 🚀, Bug Fixes 🐛, Performance ⚡, Refactoring 🛠️).
- Identifies modified High Blast Radius infrastructure, CI/CD, and security files.
- Lists Release Contributors with commit counts and contribution shares.
5. Unit Tests and Mocks (`pkg/github/client_test.go`):
- Added unit tests with mock HTTP test servers for `GetReleaseByTag`, `GetReleaseByID`, `CreateRelease`, `UpdateRelease`, and `PublishOrUpdateReleaseNotes` (both create-new and update-existing scenarios).
6. Documentation:
- Updated `README.md` with CLI commands and a complete GitHub Actions release publishing workflow.
