feat: Semantic Version bump recommendation (--suggest-bump)

## Summary
This PR introduces the ability to deterministically recommend the next Semantic Version bump (`--suggest-bump` or `--target=release --suggest-bump`) based on Conventional Commits and file diff deltas across releases and pull requests.

It removes guesswork and custom shell regex from CI/CD delivery pipelines, enabling fully automated, repeatable, and standards-compliant SemVer bumping.

### Key Capabilities
1. Deterministic Bump Evaluation (`pkg/analyzer`):
- MAJOR: If any breaking changes (`feat!:`, `fix!:`, `refactor!:`, or `BREAKING CHANGE:` in subject/body) or database schema migrations (`*.sql`, `migrations/`) are detected.
- MINOR: If new features (`feat:`, `feat(...)`) are present without breaking changes.
- PATCH: If only bug fixes (`fix:`), performance optimizations (`perf:`), documentation (`docs:`), chores (`chore:`), or test additions are present.
- NONE: If no commits or file changes are detected across the comparison range.
2. Next Semantic Version Calculator:
- Computes next SemVer string based on latest repository release tag (e.g. `v0.4.0` + `MINOR` -> `v0.5.0`, `v0.4.0` + `MAJOR` -> `v1.0.0`, `v0.4.0` + `PATCH` -> `v0.4.1`).
- Preserves SemVer tag formats (with or without `v` prefix).
3. GitHub Action Integration (`action.yml`):
- Added input `suggested-bump: 'true'`.
- Exposes action outputs: `suggested-bump` (e.g. "minor") and `suggested-version` (e.g. "v0.5.0").
- Also exposes `version`, `version_number`, `is_new_version`, and `major_tag` for direct plug-and-play usage in release workflows.
4. Release Workflow Automation (`.github/workflows/release.yml`):
- Updated `Calculate Semantic Version` step to run `go run ./cmd/gh-stats --target=release --suggest-bump`, replacing custom shell regex with deterministic analysis and emitting SRE readiness directly to `$GITHUB_STEP_SUMMARY`.
5. Local Git Tag Utilities (`pkg/gitutil`):
- Added `GetLatestTag()` supporting full SemVer ordering via `git tag -l "v*.*.*" --sort=-v:refname`.
- Added `IsSemverTag()` helper for tag validation.
6. Documentation & Step Summary Reporting (`pkg/reporter`, `README.md`):
- Added `Recommended Bump` metric row in Release Step Summary Markdown table.
- Added comprehensive section in `README.md` detailing CLI usage, Conventional Commit rules, and GitHub Actions integration.
