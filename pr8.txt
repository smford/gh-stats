feat: Release Comparison Mode (--target=release or --target=range)

## Summary
This PR introduces **Release Comparison Mode** (`--target=release` or `--target=range`) to `gh-stats`, providing automated delta analysis, deployment readiness evaluation, and SRE risk scoring across release milestones and commit ranges.

Preparing a release candidate or deploying a milestone requires understanding the full scope of changes between tags. Without automated delta analysis, teams often ship silent breaking changes, undocumented migrations, or unreviewed infrastructure alterations.

### Key Capabilities
1. **Smart Tag Auto-Detection (`pkg/gitutil`):**
   - Running `gh-stats --target=release` automatically detects the latest two SemVer release tags (e.g. `v0.3.0` and `v0.4.0`) via `git tag --sort=-v:refname` and calculates the delta.
   - If `--head` is specified without `--base` (e.g. `--head=v0.4.0`), automatically discovers the preceding release tag (`v0.3.0`).
   - Supports custom git references via `--base` and `--head` (e.g. `--base=v0.2.0 --head=v0.4.0` or `--base=v0.4.0 --head=HEAD`).
   - `--target=range` is fully supported as an intuitive alias.
2. **Release Delta & Velocity Analyzer (`pkg/analyzer`):**
   - Calculates total additions, deletions, net line delta, file counts, and breakdown (production code, tests, documentation, generated files).
   - Evaluates test-to-code velocity ratio across the release milestone.
   - Aggregates unique release contributors with commit counts and percentage shares.
3. **Breaking Change & Schema Migration Detection:**
   - Detects Conventional Commits breaking changes (`feat!:`, `fix!:`, `refactor!:`, or `BREAKING CHANGE:` in subject/body).
   - Identifies database schema migration files (`*.sql` or `migrations/`) modified in the release window.
4. **Release Blast Radius Identification:**
   - Highlights changes to CI/CD workflows, infrastructure manifests (Terraform, Kubernetes, Docker), authentication logic, and core dependencies between releases.
5. **Deployment Risk Scoring & Quality Gates:**
   - Evaluates a numerical release risk score (0–100) and qualitative risk level (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`) based on breaking changes, database migrations, change volume, test velocity, and blast radius.
   - Blocks deployment workflows when risk meets or exceeds configured thresholds via `--fail-on=HIGH` or `--fail-on=CRITICAL`.
6. **SARIF Code Scanning Rules & Annotations (`pkg/analyzer`):**
   - `GHSTATS201-RELEASE-SUMMARY`: Release comparison delta, velocity metrics, and deployment readiness summary.
   - `GHSTATS202-RELEASE-BREAKING`: Warns when breaking changes or database migrations are detected in the release delta.
   - `GHSTATS203-RELEASE-BLAST-RADIUS`: Warns when high-blast-radius infrastructure, CI/CD, or security files are modified across releases.
7. **Release Markdown Summary & Changelog (`pkg/reporter`):**
   - Generates release comparison tables for `$GITHUB_STEP_SUMMARY` and stdout.
   - Automatically groups commits into semantic changelog sections: Features (🚀), Bug Fixes (🐛), Performance (⚡), and Refactoring (🛠️).
8. **DORA Observability Telemetry Export (`pkg/exporter`):**
   - Adds `ReleaseMetrics` to `DORAMetricsPayload` when `target == "release"`, exporting commit counts, contributor counts, breaking changes, test ratio, and blast radius to JSON or webhook endpoints.
9. **GitHub Action & Documentation Updates:**
   - Updated `action.yml` inputs and added outputs: `release-base-ref`, `release-head-ref`, `release-commits-count`, `release-breaking-count`, `release-risk-level`, and `release-risk-score`.
   - Updated `README.md` and `.gh-stats.yml` with comprehensive documentation, CLI usage examples, and a complete GitHub Actions release workflow.
10. **Synthetic Testing & Manual Workflow:**
   - Added end-to-end synthetic test suite in `pkg/analyzer/release_test.go` and `scripts/test-synthetic-release.sh`.
   - Added manually triggered GitHub Actions workflow `.github/workflows/test-release-comparison.yml` (`workflow_dispatch`).

- `pkg/analyzer/release.go` & `release_test.go`: Created `ReleaseStats`, conventional commit categorization, breaking change detection, release risk scoring, SARIF population, and synthetic release comparison test.

- `scripts/test-synthetic-release.sh`: End-to-end synthetic release test script verifying tags, conventional commits, migrations, SARIF, and DORA JSON output.
- `.github/workflows/test-release-comparison.yml`: Manually dispatched workflow (`workflow_dispatch`) to test synthetic and live release comparison.
- `action.yml`: Documented release/range target options, updated base/head descriptions, and exposed release action outputs.
- `.gh-stats.yml`: Updated configuration comments for release mode quality gate.
- `README.md`: Documented Release Comparison Mode with architectural details, sample step summary, Actions workflow example, and CLI flags.
