Model code change risk like Google SRE error budgets: track rolling risk points, detect accelerated burn rates, and halt destabilizing merges.

Rolling Git Window History

Mines historical merged PR commits on the base branch across a rolling window (e.g. 30 days) using native git log numstat analysis with zero external databases.

SLO Burn Rate Multiplier

Quantifies risk consumption velocity relative to sustainable rate (Burn Rate = Observed Daily Rate / Sustainable Daily Rate), alerting at elevated (≥1.0x) and critical (≥1.5x) burn paces.

Get Started in Seconds

Deploy in GitHub Actions, install via Homebrew, or integrate shift-left git hooks locally.

.github/workflows/pr-stats.yml 
# .github/workflows/pr-stats.yml
name: PR Reliability & Stats

on:
  pull_request:
    branches: [ main ]

permissions:
  contents: read
  security-events: write   # Uploads SARIF to GitHub Code Scanning
  pull-requests: write     # Posts sticky summary comment

jobs:
  gh-stats:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0  # Required for full git diff analysis

      - uses: smford/gh-stats@main
        with:
          target: pr
          comment-pr: 'true'
          fail-on: 'CRITICAL'
          token: ${{ secrets.GITHUB_TOKEN }}

🏷️ Standards-Compliant SARIF Rules

Published directly to GitHub Security Code Scanning tab for automated auditability.

Rule ID Severity Scope Condition & Guidance
GHSTATS001-PR-SUMMARY NOTE PR Overall SRE health scorecard, lines added/deleted, test-to-code velocity delta.
GHSTATS002-PR-SIZE WARNING PR PR exceeds size limits (>800 lines), elevating cognitive review fatigue and outage risk.
GHSTATS003-PR-TEST-RATIO WARNING PR Significant production logic changed without corresponding automated test delta.
GHSTATS004-PR-BLAST-RADIUS WARNING PR Modifications to CI/CD workflows, Terraform/k8s manifests, auth, or DB schema migrations.
GHSTATS005-PR-STALE WARNING PR PR open >14 days, indicating branch drift, painful merge conflicts, and delayed lead time.
GHSTATS006-PR-DISCUSSION-CHURN NOTE PR High comment volume (>15 comments) signalling review friction or architectural ambiguity.
GHSTATS007-PR-REVIEWERS NOTE PR Domain experts recommended to review modified files based on historical commit patterns.
GHSTATS008-PR-CI-LATENCY WARNING PR CI check run exceeds latency threshold (>15 min), inflating developer turnaround times.
GHSTATS009-PR-CI-FLAKINESS WARNING PR Check run failed initially but passed on retry on the exact same commit SHA without code changes.
GHSTATS010-RISK-BUDGET-EXCEEDED ERROR PR Squad PR risk budget or critical PR limit exceeded in rolling window, burning risk points too fast.
GHSTATS101-REPO-SUMMARY NOTE Repo Repository architecture summary, test density percentage, and language distribution.
GHSTATS102-REPO-HOTSPOTS NOTE Repo Frequently modified files identified across historical commit logs (churn hotspots).
GHSTATS103-REPO-BUS-FACTOR WARNING Repo Single contributor accounts for >75% of commits, highlighting knowledge silo risk.
GHSTATS201-RELEASE-SUMMARY NOTE Release Release comparison delta, velocity metrics, conventional changelog, and readiness summary.
GHSTATS202-RELEASE-BREAKING WARNING Release Breaking changes (feat!:, BREAKING CHANGE:) or database schema migrations detected.
GHSTATS203-RELEASE-BLAST-RADIUS WARNING Release Modifications to critical deployment pipelines, cloud infrastructure, or security modules.
GHSTATS301-DRIFT-SUMMARY NOTE Drift Environment drift assessment, ahead/behind commits, and promotion deployment readiness.
GHSTATS302-DRIFT-EXCESSIVE WARNING Drift Excessive branch divergence detected between promotion environments (>20 commits).
GHSTATS303-DRIFT-UNPROMOTED-BREAKING WARNING Drift Unpromoted breaking changes (feat!:) or database migrations pending in candidate branch.
GHSTATS304-DRIFT-UNPROMOTED-SENSITIVE WARNING Drift Unpromoted sensitive infrastructure, CI/CD pipeline, or security configuration changes.
